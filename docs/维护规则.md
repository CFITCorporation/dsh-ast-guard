# 规则参考（API 级）

> 读者：**要改这套规则的人或智能体**。目标：**读完不用看源码**就能写对、改对、验对。
> 本文的每条语义都对着代码核过；有"实测"标记的是当场跑探针验的（`compileRules` 直接调，无副作用）。

---

## 1. 文件结构

规则文件是一个 **YAML 映射**（不是列表）。顶层只认三个键，其它**静默忽略**：

```yaml
version: 1        # 可选，目前**不校验**（缺了、写成字符串都 OK）；保留给将来做版本迁移
deny: []          # 可选，列表。命中 = 直接拒绝
deliberate: []    # 可选，列表。命中 = 进三思（冷却窗口）
```

- 两个列表里**各自**都是"规则对象"的列表；写成对象（不是列表）会报 `deny 必须是列表`。
- 顶层是数组会报 `规则文件的顶层必须是映射（version / deny / deliberate）`。
- 两个键都省略 = 空规则集（不会报错，也什么都不拦）。

---

## 2. 规则通用字段（`deny` 与 `deliberate` 都有）

| 字段 | 类型 | 必填 | 默认 | 语义 |
|---|---|---|---|---|
| `id` | string | **是** | — | 规则标识。**会进文案**（`[ast-guard] 拒绝：<id>`）。**重复不报错、两条都生效** —— 自己保证唯一 |
| `enabled` | bool | 否 | `true` | `false` = **整条跳过**（连字段校验都不做，可以留半成品） |
| `why` | string | 否 | `''` | **会逐字进文案**（拒绝文案 / 三思窗口）。写"为什么拦 + 该怎么做"，这是最主要的教学位 |
| `commands` | string[] | 见下 | `[]` | 命令名（大小写不敏感）。**别名必须逐条写**——语法树不解析别名 |
| `when` | map | 否 | — | 逐命令参数条件，见 §4 |

> `deny` 至少要有一个"匹配维度"（`commands` / `memberNames` / `redirects` / `when` / `tools` / `paths` / `mentions`），
> 否则报 `deny[<id>] 什么都没配（…）`。
> `deliberate` 的 `commands` **必须非空列表**，否则报 `deliberate[<id>].commands 必须是非空列表`。

---

## 3. 两档规则专属字段

### 3.1 `deny`（直接拒绝）

| 字段 | 类型 | 语义 |
|---|---|---|
| `memberNames` | string[] | .NET 成员名（大小写不敏感）。如 `WriteAllText` / `Create` |
| `memberTargetContains` | string[] \| string | **按调用目标原文**做子串匹配（**大小写敏感**）。用来把 `[IO.File]::Create` 和 `[scriptblock]::Create` 分开 |
| `redirects` | bool | `true` = 把文件重定向 `>` / `>>` 也算命中。**目标是 `$null` 的自动豁免**（那是抑制输出） |
| `tools` | string[] | **非 shell 工具**名（`edit` / `write` …）。配了它就**必须**再给 `paths` 或 `mentions`，否则报错 |
| `paths` | string[] | **规则级**路径 needle：与 `commands` **相与**（命令名命中 + 参数含该子串）。**大小写不敏感** |
| `mentions` | string[] | **提及即停**：命令名或任意字符串参数里**含**该子串就命中（**大小写不敏感**）。可以单独用，不需要 `commands` |

### 3.2 `deliberate`（三思）

| 字段 | 类型 | 必填 | 默认 | 语义 |
|---|---|---|---|---|
| `cooldownSeconds` | number | 否 | `10` | 冷却秒数，**必须 ≥ 10**，否则报 `必须 ≥ 10（用户定的下限）` |
| `evidence` | string[] | 否 | `[]` | 进窗口**前**跑的**只读**探针命令。**含写动词会被编译期拒绝**（`evidence 里有写动词，探针必须只读`） |

## 4. `when`：逐命令参数条件

**只对"这条命令自己的参数"求值** —— 同行别的命令的 `-p` / `-c` 不会串进来（这正是本层比文本匹配准的地方）。

| 维度 | 类型 | 语义 | 大小写 | 备注 |
|---|---|---|---|---|
| `flags` | string[] | 参数是某个标志的**前缀**即命中（`-Rec` ⇒ `-Recurse`） | 不敏感 | **必须列表**；写成字符串会抛 JS 报错。裸 `--` 不算标志 |
| `wildcard` | bool | 参数里出现 `*` 或 `?` | — | `true` 才开 |
| `paths` | string[] | 参数**包含**该子串 | **敏感** ⚠️ | 与规则级 `paths`（不敏感）**不一样**，这是已知的不一致 |
| `subcommands` | string[] | **第一个位置参数**（跳过取值型全局选项及其值） | 不敏感 | 外部命令（`reg`/`git`）适用；**cmdlet 的第一个位置参数是路径**，不要用这维 |
| `argsExact` | string[] | 参数**整个等于**其中一项 | 敏感 | 用来表达"目标是整棵树"的 `.` |
| `argsContain` | string[] | 参数**包含**该子串 | 不敏感 | 用来兜"字符串里的写命令"：`iex "Set-Content …"` |
| `all` | condition[] | **分组相与**：每组都要成立（组内仍是 OR） | — | ⚠️ **仅 `deliberate` 支持**；`deny` 里写 `all` 会报"什么都没配" |

**坑（实测）**：维度名写错**不会**提示名字，只会报 `deliberate[<id>].when 什么都没配（…）`
—— 换句话说 **写错维度名 = 规则悄悄失效**。改完一定跑用例。

---

## 5. 求值顺序与组合

1. **`deny` 整体先于三思**：一条命令只要命中任何 `deny` 规则就直接拒，不会进三思窗口。
2. **同一档内按声明顺序，先命中者生效**：`deny` 与三思都是"遇到第一个命中的规则就返回"。
   ⇒ **顺序有语义**：把宽规则写在窄规则前面，后面的永远不会被看到。
3. **一条规则内**：`commands` / `memberNames` / `redirects` / `when` / `tools`+`paths` / `mentions`
   是**与**关系（都要成立）；`when` 的**各维度之间是或**（命中任一即算这条条件成立），`when.all` 里的**组之间是与**。

## 6. 运行期行为

| 行为 | 说明 |
|---|---|
| 规则热更新 | 按**文件 mtime** 缓存：改了规则文件**立即生效**，不用重启 |
| 代码热更新 | ❌ **不热**：改了 `lib/*.js` 要**重启宿主**才生效 |
| 规则文件默认位置 | **包内** `rules/default.yaml` |
| 配了 `rulesFile` | 相对**会话 cwd** 解析；也可以写绝对路径 |
| 配了路径但文件不存在 | **本层无意见**（不是错误） |
| **默认**规则文件不存在 | **当错误处理** ⇒ 走 `onRuleError: closed` ⇒ 拒绝并说明（"安装不完整？"） |
| 解析器不可用 | 走 `failPolicy`：`closed`（默认）= 拒绝并说明；`open` = 放行 |
| 规则文件读坏 | 走 `onRuleError`：`closed`（默认）= 拒绝并说明怎么修；`open` = 放行 |
| 三思·冷却 | `cooldownSeconds`（≥10）；**窗口内回答"是"和"否"都无效** |
| 三思·确认窗口 | 冷却结束后 60 秒内可以确认（`confirmWindowMs`） |
| 三思·待确认保留 | 2 分钟不处理自动作废（`pendingTtlMs`） |
| 三思·一次性放行 | 绑**命令哈希**；用掉或过期即作废；**按会话隔离** |

## 7. 编译错误对照表（照报文找原因）

| 报文（片段） | 原因 |
|---|---|
| `规则文件的顶层必须是映射` | YAML 顶层写成了列表/字符串 |
| `deny 必须是列表` / `deliberate 必须是列表` | 该键写成了对象 |
| `deny[<i>] 缺 id` | 少 `id` |
| `deny[<id>] 什么都没配（…）` | 没有任何匹配维度；**也可能是维度名拼错了** |
| `deny[<id>] 配了 tools 但既没有 paths 也没有 mentions` | `tools` 必须配路径或提及 |
| `deliberate[<id>].commands 必须是非空列表` | 三思规则没写命令 |
| `deliberate[<id>].cooldownSeconds 必须 ≥ 10` | 冷却写小了 |
| `deliberate[<id>].evidence 里有写动词` | 探针不是只读 |
| `(raw.flags ?? []).map is not a function` | `flags`（或其它 `when` 维度）写成了字符串而不是列表 |

## 8. 加规则：四步

1. 写进规则文件（自己部署里就是 `rulesFile` 指向的那个；包内默认是 `rules/default.yaml`）；
2. **先跑对照**：`node test/smoke.mjs`（裁决）、`node test/hook.mjs`（接线与 fail-closed）；
3. **补对照**：每条"该拦"必须配一条"不该拦"。**没有对照的规则等于没验**；
4. 真实使用里观察，把误报当 bug 处理。

## 9. 永远不要做的三件事

1. **不要留反向后门**：让某条规则"整体放行"的写法会短路后面对它的所有判断 —— **宁可少拦，不留后门**。
2. **不要用内容白名单收窄内联代码**（"代码里没有 fs. 就放行"）：那就是后门，判据只能是形状。
3. **不要静默放行**：一个"看起来在拦、其实没判"的守卫，比多一条误报贵得多。

## 10. 结构性盲区（写规则时别假装能拦）

- 字符串里的代码：`iex $code`、`Start-Process … -ArgumentList`、`[scriptblock]::Create("…")`、`cmd /c "…"`；
- 脚本内部的路径与行为（规则只看命令行文本）；
- 只接 `pwsh` / `powershell`；`bash` 不在范围内。

## 11. `ast_confirm` 工具的接口

三思窗口里唯一有效的回答方式。**不带编号的回答一律无效。**

| 参数 | 类型 | 必填 | 语义 |
|---|---|---|---|
| `id` | string | **是** | 窗口里显示的"待确认编号"。对不上就拒绝 |
| `decision` | `"yes"` \| `"no"` | **是** | `yes` = 放行**这一次**；`no` = 放弃 |
| `command` | string | 否 | 可选：附上你确认的那条命令原文。给了就必须**逐字**与被待确认的那条一致（用来防"确认了别的"） |

返回：`{ accepted: boolean, message: string, reason?: string, remainingSeconds?: number }`

- 冷却未满 ⇒ `accepted: false`、`reason: "too-early"`、`remainingSeconds` 有值；
- 编号对不上 / 没有待确认项 / 已过期 / 命令原文不一致 ⇒ `accepted: false` + 对应 `reason`；
- 接受后**一次性放行**生效：绑该命令的哈希，用掉或过期即作废。

> 用法：把命令**原样**重发一次即可（不要改任何一个字符，否则哈希对不上）。

## 12. 完整示例（带注释）

```yaml
version: 1

deny:
  - id: no-write-verbs
    why: |
      PowerShell 写文件内容已禁用：会破坏编码，而且 shell 写入没有 diff、进不了回退。
      正确姿势：定点替换用 edit；整份新写用 write。
    commands: [Set-Content, sc]          # 别名要逐条写
    memberTargetContains: ['File', 'Stream']
    memberNames: [WriteAllText, Create]
    redirects: true
    when:
      flags: ['-e', '-p']                # 列表；前缀即命中
      argsContain: ['set-content']       # 只对这条命令自己的参数求值

  - id: protect-credentials
    why: |
      凭据文件只许走专门的流程。
    tools: [edit, write]
    paths: ['.npmrc', 'id_rsa']          # 只比路径型参数，不碰正文

  - id: naming-convention
    why: |
      名字里带这个字样的目录"提及即停"。
    mentions: ['DO-NOT-RUN']             # 可以单独用，不需要 commands

deliberate:
  - id: ask-before-delete                 # 简单三思：条件之间是"或"
    cooldownSeconds: 10
    why: |
      删除不可逆。更便宜的做法：先 Copy-Item 备份，或别删只挪。
    commands: [Remove-Item, ri, rm]       # 必须非空
    when:
      flags: ['-recurse', '-force']
      wildcard: true
      paths: ['src', 'docs']

  - id: ask-before-scope-revert           # 用 all 的三思：两组条件都成立才停
    cooldownSeconds: 10
    why: |
      git 的范围收缩会丢掉工作区内容，而未提交的部分不进 reflog。
    commands: [git]
    when:
      all:
        - subcommands: [checkout, restore, reset, clean]
        - argsExact: ['.']
          flags: ['--hard', '-f', '-fd']
    evidence:
      - git status --porcelain            # 只读探针：进窗口前现跑，把"会丢什么"算出来
      - git ls-files --others --exclude-standard
```
