# 维护规则（给智能体与维护者）

> 这份文档的对象是**要改这套规则的人或智能体**。读完应该能做到：加一条规则、验证它、并且不把它写成后门。

## 0. 先理解三件事

1. **规则的 `why` 就是文案**：它会**逐字**出现在拒绝 / 三思窗口里 —— 写 `why` 等于写给"下一个读到它的人"看的话。
2. **按效应判断，不按命令名**：`Remove-Item` 清临时文件是日常，`-Recurse` 到 `src` 才该停。
   所以优先写"**什么条件下才算贵**"，而不是"凡是这个命令就拦"。
3. **失败必须响**：规则读坏、解析器起不来 ⇒ 拒绝并说明（`fail-closed`）。
   **永远不要**为了"看起来正常"改成静默放行 —— 这条教训本项目付过代价。

## 1. 加一条规则：四步

1. 写进 `rules/default.yaml`（自己的部署里，就写 `rulesFile` 指向的那个文件）；
2. **先跑离线用例**：`node test/smoke.mjs`（拒绝/放行对照）、`node test/hook.mjs`（接线与 fail-closed）；
3. **补对照**：每条"该拦"都配一条"不该拦"。**没有对照的规则等于没验** —— 这是本项目的硬规矩；
4. 真实使用里观察一段时间；把误报当 bug 处理，不要当噪音。

## 2. 维度速查（`when` 里能写什么）

| 维度 | 语义 | 坑 |
|---|---|---|
| `flags` | 参数是某个标志的**前缀**即命中（`-Rec` ⇒ `-Recurse`） | 大小写不敏感；裸 `--` 会被排除（它是"选项结束"，不是标志） |
| `wildcard` | 参数里出现 `*` 或 `?` | —— |
| `paths` | 参数**包含**该子串 | 不是 glob；区分不了"这个参数是路径还是普通值" |
| `subcommands` | 取**第一个位置参数** | 对 `reg` / `git` 这类外部命令好用；**cmdlet 的第一个位置参数是路径、不是子命令** —— 混用会让那一半永远不命中（踩过，藏了七天） |
| `argsExact` | 参数**整个等于** | 用来表达"目标是整棵树"的那个 `.` |
| `argsContain` | 参数**包含**（大小写不敏感） | 用来兜"字符串里的写命令"：`iex "Set-Content …"` |
| `all` | 上面这些**分组相与**（组内仍是 OR） | 用来区分"看起来像"和"真的贵" |

**工具参数那一支**（`tools` / `paths` / `mentions`）不经过 shell：**只比路径型参数，不碰正文** ——
所以在文件里"提到"某个名字是正当的。

## 3. 踩过的坑（写规则前读一遍）

- **别名要逐条写死**：语法树不解析别名（`sc` 就是 `sc`，认不出它是 `Set-Content`）。
  别名以本机 `Get-Alias -Definition <规范名>` 的**实测**结果为准，别凭记忆。
- **同一个开关在不同解释器上含义不同**：`python -c` 跑代码，`node -c` 是**语法检查** ⇒ 别共用一张开关表。
- **`args[0]` 是命令名**：取"第一个位置参数"必须跳过它，否则整维失效。
- **YAML 单引号不做转义**：`'记忆\\流水.md'` 得到两个反斜杠，永远匹配不上。
- **动态代码看不见**：`iex $code`、`Start-Process … -ArgumentList`、`[scriptblock]::Create("…")`、
  `cmd /c "…"` 都读不到内层内容 —— 这是**结构盲区**，写进边界，别假装能拦。

## 4. 永远不要做的三件事

1. **不要加"反向后门"**：比如给某条规则加个 `exclude` 让它整体放行 —— 一旦放行就短路了后面对它的所有判断。
   **宁可少拦，不留后门。**
2. **不要用"内容白名单"收窄内联代码**（"只要代码里没有 fs. 就放行"）：那就是后门；判据只能是形状。
3. **不要静默放行**：一个"看起来在拦、其实没判"的守卫，比多一条误报贵得多。

## 5. 怎么验

| 命令 | 覆盖 |
|---|---|
| `node test/smoke.mjs` | 30 条拒绝 / 放行对照；只解析、不执行 |
| `node test/hook.mjs` | 12 条走真 `apply()`：钩子注册、规则加载、非 shell 分支、fail-closed、文案组装、三思窗口 |
| `node test/import-check.mjs` | 入口能否被装载（不启动） |

改完必须都绿。**新增一个维度或一组规则，要同时加进这两个测试文件** —— 没有用例的维度不算支持。

## 6. 三思层的行为（改它之前先懂它）

- 冷却窗口内**回答"是"和"否"都无效**（故意的，逼你停下来重看）；
- 一次性放行**绑命令哈希**：用掉或过期即作废，不会留到下一次；
- 进窗口**之前**先跑规则里声明的**只读探针**（`evidence`），把"这条命令会丢什么"现算出来；
- 探针里**不许出现写动词**（编译期会拒 —— 探针必须是只读的）。
